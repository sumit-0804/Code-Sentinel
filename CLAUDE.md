
## Code Comments

* Use **single-line comments only**.
* Do not use multi-line comments, block comments, or documentation blocks unless I explicitly request them.
* Keep comments minimal and only add them when they provide useful context.
* Do not add unnecessary comments that merely restate what the code does.

## Git Commits

* Commit messages must be **3–4 words maximum**.
* Use a concise, imperative commit message.
* Do not add a commit body.
* Do not add `Co-Authored-By` or any other co-author attribution.
* Do not add trailers, metadata, signatures, or AI attribution.
* Do not add emojis or unnecessary prefixes.
* Do not include any "Generated by Claude" or similar text.
* Example: `Fix login validation`
* Example: `Update API handler`
* Example: `Remove unused imports`

## Git Safety

* Never commit unless I explicitly ask you to commit.
* Never push unless I explicitly ask you to push.
* Never force-push.
* Do not modify unrelated files.

## General

* Follow existing project conventions.
* Keep changes minimal and focused.
* Do not introduce unnecessary dependencies.
* Before making significant changes, inspect the relevant existing code.
* Do not over-engineer solutions.
* If requirements are ambiguous, ask before making assumptions.
